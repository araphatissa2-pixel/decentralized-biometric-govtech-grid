# 🏛️ Decentralized Biometric Public Security Grid

## 1. Project Overview
A Zero-Trust Distributed Biometric Surveillance and Identity Management Ecosystem.

## 2. Infrastructure Setup
- **central_brain.py**: Central Cloud Registry Hub.
- **mobile_app.py**: Desktop Phone Client Simulator.
- **packet_sniffer.py**: Low-Level Raw Internet Packet Sniffer.
- **file_vault_audit.py**: AES-256 Cryptographic Recovery Engine.

## 3. Launch Commands
```bash
python central_brain.py
python mobile_app.py
sudo python packet_sniffer.py
```
